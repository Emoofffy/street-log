# 街健日誌 — 街頭健身追蹤 App (PWA)

一個離線可用的街頭健身（Street Workout / Calisthenics）記錄工具。資料全部存在你的手機本機，不需要註冊、不需要網路。

（這份是使用者說明；要改程式或文件，先讀 [`CLAUDE.md`](CLAUDE.md) 開發導覽。）

## 功能（底部 7 個分頁）

- **🏠 首頁** — Journal 版型：今天日期＋三張入口卡（Sadhana／Physics／Journal）＋下方的備忘錄列表
- **🏋️ 日誌** — 記錄每次訓練：動作、組數、次數/秒數、負重、標籤；可從範本一鍵開始並帶入上次數字
- **🎯 技能** — 內建街健技能樹：Muscle-up、前水平、俄挺、人體國旗、倒立、L-sit，逐階段解鎖；也可自訂技能
- **🏆 紀錄** — 個人最佳成績（最多次數、最長秒數、負重），自動畫成長曲線；訓練日誌會自動更新 PR
- **📈 身體** — 體重/體脂趨勢圖、每週訓練課表安排
- **📊 回顧** — 週/月/年/全部統計、訓練頻率熱力圖、PR 與體重亮點
- **🪞 省思** — 每日內省書寫：自由文字＋可插入的省思格式表格

不在分頁列、從首頁進入的三項：

- **🪷 Sadhana 修練頁** — 從首頁 Sadhana 卡進入。起床按兩次（醒來／起身，躺床時長自動算），
  練習點名字就開始計時，Finished 之後一頁一題記錄品質（專注／呼吸／細微／samyama…）。
  群組、項目、每項要記哪些參數、固定時刻（吃飯）、鏈（順序不可換的一組）都能在 App 內設定。
- **📝 備忘錄** — 列表在首頁下方；點 **Journal 卡**直接開始寫今天那則（同一天再點是續寫），
  點區塊右上的筆記本鈕開一則新的。用起來跟 iPhone 內建備忘錄一樣：整頁就是一張紙、點空白處接著寫，
  第一行自動變標題，邊打字邊存（沒有存檔鈕）。底下那排可以插入標題、勾選清單、項目清單、粗體，
  以及**省思格式**：一次把省思分頁那整套面向（進食／回應／接納…）連引導問題插進來，自成一個上下有線的區塊。
  它是**插進文件裡的一塊**，插在游標所在的位置——開頭、中間、結尾都行，前後永遠留得下可以繼續打字的段落。
  **游標在省思裡**＝整份題目都還在，只是可視範圍縮成一個小視窗，在裡面**上下捲動**看下一題
  （頂上黏著「3 / 7」看得出位置，捲到哪題那題就變亮、其餘變暗），也可以點**頂端主題列**跳題
  （作答完的會亮一個點）；
  **游標移到省思以外**（去寫筆記的其他段落）或按了「完成」＝自動收成點列，只留寫過的那幾題，沒寫的跳過。
  點那幾行就會再展開，而且直接停在你點的那一題。面向的內容以省思分頁的「⚙︎ 面向」為準。
  往左滑一則會出現刪除；區塊右上的「編輯」也可以刪。
- **💾 備份** — 首頁 ⚙️ 設定裡可「匯出/匯入 JSON」，換手機或清瀏覽器前記得先備份

## 怎麼在電腦上打開

在這個資料夾執行本機伺服器（Service Worker 需要 http，不能直接雙擊開檔）：

```bash
cd /Users/chuan/Desktop/CODE/training
python3 -m http.server 8734
```

然後瀏覽器打開 <http://localhost:8734>

## 怎麼變成手機 App（加到主畫面）

要在手機上用，需要讓手機連得到這個網頁。兩種方式：

1. **同一個 Wi-Fi**：電腦跑上面的伺服器，手機瀏覽器輸入 `http://<電腦區網IP>:8734`
2. **免費部署上線**（推薦，之後隨時可用）：把這個資料夾丟到 Netlify Drop / GitHub Pages / Vercel，會得到一個網址

打開網頁後：
- **iPhone (Safari)**：分享鈕 → 加入主畫面
- **Android (Chrome)**：右上選單 → 加到主畫面 / 安裝應用程式

加完後桌面會出現 App 圖示，點開就是全螢幕、離線可用，跟原生 App 幾乎一樣。
